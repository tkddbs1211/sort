과제 10: 정렬 알고리즘의 성능 및 안정성 비교
1. 개요
본 과제는 컴퓨터공학 알고리즘 학습의 일환으로, 대표적인 O(n^2) 정렬 알고리즘인 선택 정렬(Selection Sort), 버블 정렬(Bubble Sort), 삽입 정렬(Insertion Sort)을 직접 구현하고, 다양한 입력 데이터 상태에 따른 성능(비교 횟수 및 데이터 이동 횟수)과 안정성(Stability)을 분석하는 것을 목적으로 합니다.

2. 데이터 생성 및 실험 방법
데이터 구성: 0부터 1,000,000 사이의 난수로 생성된 두 개의 키(Key 1, Key 2)와 원래의 입력 순서를 보존하는 original_index를 포함하는 DataItem 구조체를 사용했습니다.

데이터 개수: 총 10,000개

무작위 데이터 100회 실험: 동일한 난수 시드 환경에서 100회 반복하여 각 알고리즘의 총 비교 횟수와 평균 비교/이동 횟수를 측정했습니다.

부분 정렬 데이터 생성 방법:

오름차순으로 완벽히 정렬된 데이터를 기준으로 삼았습니다.

전체 데이터 개수의 5퍼센트(500회)에 해당하는 횟수만큼 무작위로 두 인덱스를 선택하여 원소를 상호 교환(Swap)하는 방식을 사용하여 일부만 정렬이 깨진 상태의 데이터를 생성했습니다.

3. 무작위 데이터 실험 결과 (100회 평균)
선택 정렬:

평균 비교 횟수: 약 49,995,000회

평균 이동 횟수: 정렬 완료를 위해 고정적인 교환 연산 수행

버블 정렬:

평균 비교 횟수: 약 49,995,000회

평균 이동 횟수: 인접 원소 간 빈번한 교환으로 매우 높은 이동 횟수 기록

조기 종료 버블 정렬:

무작위 데이터에서는 대부분의 순회에서 교환이 발생하므로 일반 버블 정렬과 유사한 비교 횟수를 보이지만, 정렬이 완료되는 시점에 따라 약간의 차이가 발생합니다.

삽입 정렬:

평균 비교 횟수: 무작위 데이터 기준 약 25,000,000회 내외로 선택 및 버블 정렬 대비 약 절반 수준의 비교 횟수를 기록했습니다.

4. 버블 정렬 조기 종료 조건 분석
구현 방식: 한 번의 패스(Pass) 동안 인접한 원소 간의 교환(Swap)이 단 한 번도 일어나지 않았다면, 이미 모든 데이터가 정렬된 상태로 판단하고 반복문을 즉시 탈출하도록 구현했습니다.

성능 영향:

이미 정렬되어 있거나 일부만 정렬된 데이터에서 극적인 성능 향상을 보입니다.

완전 정렬된 데이터의 경우 조기 종료 조건 덕분에 단 1회의 패스만 수행하고 종료되므로, 비교 횟수가 n-1회로 대폭 감소합니다.

5. 정렬 알고리즘 안정성(Stability) 검증
검증 방법: 첫 번째 키(Key 1)가 동일한 데이터 그룹에서 정렬 전의 original_index가 정렬 후에도 오름차순을 유지하는지 확인하는 verify_stability 함수를 구현하여 검증했습니다.

선택 정렬: Unstable (불안정 정렬)

최솟값을 찾아 맨 앞의 원소와 강제로 교환하는 과정에서 멀리 떨어져 있던 동일한 값의 상대적 순서가 깨질 수 있습니다.

버블 정렬: Stable (안정 정렬)

인접한 두 원소가 엄격하게 클 때만 교환(>)하므로, 같은 값일 때는 자리가 바뀌지 않아 기존 순서가 유지됩니다.

삽입 정렬의 비교 연산자(> vs >=)에 따른 차이:

Case A (data[j].key1 > current.key1): 삽입 과정에서 자신과 같은 값을 만나면 멈추기 때문에 기존 순서가 유지되어 Stable합니다.

Case B (data[j].key1 >= current.key1): 자신과 같거나 큰 값을 모두 뒤로 밀어내기 때문에, 나중에 입력된 데이터가 기존의 동일한 값보다 앞으로 배치되어 Unstable하게 바뀝니다.

6. 입력 데이터 상태에 따른 성능 분석
이미 정렬된 데이터 (Sorted Data)

삽입 정렬: 최선의 시나리오로 동작하여 비교 횟수와 이동 횟수가 가장 적습니다 (O(n)).

버블 정렬 (조기 종료): 단 1회의 패스만 수행하므로 비교 횟수가 급격히 줄어듭니다.

선택 정렬: 정렬된 상태라 할지라도 모든 원소를 순회하며 최솟값을 탐색해야 하므로 비교 횟수는 여전히 O(n^2)로 유지됩니다.

역순으로 정렬된 데이터 (Reverse-Sorted Data)

삽입 정렬: 매 원소마다 맨 앞으로 이동해야 하므로 가장 많은 비교와 이동 연산이 발생합니다.

선택 정렬 및 버블 정렬: 최악의 비교 및 교환 연산이 수행됩니다.

일부 정렬된 데이터 (Partially Sorted Data)

삽입 정렬과 조기 종료 버블 정렬이 전체적으로 우수한 성능을 보입니다. 정렬되어 있는 구간에서는 연산이 빠르게 생략되거나 적게 발생하기 때문입니다.

7. 결론
본 실험을 통해 동일한 O(n^2) 시간 복잡도를 가지는 알고리즘이라 할지라도 입력 데이터의 초기 정렬 상태에 따라 실제 연산 횟수(비교 및 이동)에서 큰 차이가 난다는 점을 확인했습니다.
특히 삽입 정렬은 이미 정렬된 데이터에서 매우 효율적으로 동작하며, 버블 정렬에 조기 종료 조건을 추가하는 것만으로도 정렬된 입력에 대해 성능을 극대화할 수 있음을 알 수 있었습니다. 또한, 삽입 정렬에서 사용하는 조건문 부등호 하나가 알고리즘의 안정성 여부를 결정한다는 점을 이론과 코드를 통해 명확히 검증할 수 있었습니다.
